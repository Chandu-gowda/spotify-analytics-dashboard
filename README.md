# Spotify Analytics Dashboard

## Project Overview

This project analyzes Spotify music data to uncover trends in artist popularity, track performance, genre distribution, and audio characteristics. The dashboard provides interactive visualizations that help users explore listening patterns and music preferences.

## Objective

To transform raw Spotify data into meaningful insights using Power BI and create an interactive dashboard for data-driven analysis.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Key Performance Indicators (KPIs)

* Total Tracks
* Total Artists
* Average Popularity Score
* Genre Distribution
* Top Performing Artists
* Most Popular Tracks

## Key Insights

* Identified the most popular artists and songs.
* Analyzed genre-wise music distribution.
* Compared track popularity across different categories.
* Explored relationships between audio features such as energy, danceability, and popularity.
* Highlighted trends that influence listener engagement.

## Dashboard Features

* Interactive Filters
* Artist Performance Analysis
* Track Popularity Analysis
* Genre Insights
* Audio Feature Comparison

## Outcome

The dashboard enables users to quickly identify music trends and gain insights into Spotify listening behavior through interactive visualizations.
